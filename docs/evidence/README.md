# Historical evidence references

Each JSON file in this directory points to its original evidence at an immutable repository revision and records the original content SHA-256.

These are references, not newly generated test results. The original records describe the previous app identity and must not be used as signing, CloudKit or TestFlight acceptance evidence for Gumbo. Keeping the originals in Git history preserves their exact identifiers, paths, signatures and measurements.

See [Gumbo identity and distribution](../GUMBO-IDENTITY.md) for current names and release gates. Record new verification against the exact current revision in GitHub Issues and pull requests.
