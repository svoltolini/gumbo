## Access-boundary review

Complete platform verification outcome: **blocked**. Source fixes and local regression checks are complete for #15, #98, #99 and #100, but the platform evidence identified above is still needed before calling those boundaries fully verified.

The invariant is that a retired family profile, revoked Watch grant, locked profile or stale Settings/navigation callback cannot acquire current-session access. Legitimate unchanged-session activity, self profiles and unrelated account data must remain usable. Enforcement lives at the existing profile-loading, cloud-mutation, metadata-write and Watch delivery/playback boundaries; view teardown alone is not treated as authorization.

One independent pre-patch investigation and one fresh post-patch review were completed. The post-patch review identified three additional cases, all addressed with source changes and executable regressions:

- Failed retirement-marker writes now revoke memory access immediately; offline startup reads the authoritative CloudKit account journal before exposing profiles.
- Initialization and Try Again share the same fail-closed retirement-aware loader.
- Sharing actions capture authorization at the button action and revalidate after suspension before issuing a cloud mutation; NAS actions retain the same session/source checks.

The marker-write/offline-relaunch, unreadable-marker/retry, and queued/suspended lock/reopen/switch cases no longer reproduce in the injected fixtures. Successful local controls and existing family/cloud tests continue to pass. Watch tests exercise persisted authorization values and command ordering; they do not claim to execute real transport callbacks or audio activation. SwiftUI tests at the model layer do not establish actual navigation teardown on devices.

An authorized NAS file replacement already in progress may finish its current atomic swap after lock, preserving the music file. The late-upload regression confirms that the next song is not started. Revocation does not undo a completed external mutation.
